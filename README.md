Projeto do Game: I'm not generated 

-# Jogo Investigativo IA 

Projeto de desenvolvimento de um jogo **single player**, para PC, com estética **pixel art**, ambientado em um setor de cibersegurança de uma empresa de IA.

## Conceito

O jogador atua em uma estação de PC e precisa investigar um ambiente de testes após uma perda de controle, analisando comportamentos, pistas e enigmas para descobrir se determinado comportamento/personagem está associado a um humano ou a uma IA.

## Método de gestão: Scrumban

O projeto combina:

- **Scrum:** objetivos de Sprint, planejamento, Review e Retrospectiva.
- **Kanban:** fluxo contínuo, limites de WIP e gestão visual.
- **Playtest:** validação contínua com usuários.

### Fluxo

`BACKLOG → PRONTO → DESENVOLVIMENTO → CODE REVIEW → QA/PLAYTEST → CONCLUÍDO`

Coluna especial: `BLOQUEADO`

### WIP inicial

| Etapa | Limite |
|---|---:|
| Desenvolvimento | 2–3 |
| Code Review | 2 |
| QA/Playtest | 2 |

## MVP

O MVP deve entregar uma experiência curta e jogável contendo:

- 1 fase;
- exploração de ambiente;
- pelo menos 3 pistas;
- pelo menos 2 enigmas;
- comportamento suspeito de IA;
- decisão final humano × IA;
- sistema simples de dicas;
- cronômetro;
- pixel art funcional;
- áudio/narração provisórios;
- registro básico de desempenho;
- playtest com estudantes de Tecnologia.

A duração de 5, 10 ou 15 minutos é uma **hipótese a validar**, não uma decisão definitiva.
